# Output template

## Path

`organized/YYYY-MM-DD-<slug>.md`  
If the source was `.docx`, you may save `.docx` instead; keep the same stem.

`<slug>`: 3–6 lowercase words from the draft title or first claim, hyphenated.

## Required sections

```markdown
# {Title}

## Table of contents
- …

## Sections
### {Section from confirmed nodes}
{Mostly original sentences}

## TBD
- {named gap}: TBD

## Organized
- {approved addition} — source: {url or title}
```

## Rules

- Do not invent section titles the user did not confirm.
- Keep original wording whenever possible.
- Every Organized bullet needs a source if it came from search.

## Second pass

When this run is a re-organize, add under TBD (or a short "Confirmations" section):

- Inherited (kept from last pass): …
- Confirmed this pass: …
- Still TBD: …

Still save a new dated file; do not overwrite the source or the previous organized file.
