# Question prompts (one at a time)

## Confirming the node list

"Here's a first pass at your thinking nodes—anything missing or off?"

## Intent marks

- Comment: "The note says '…'. Apply that to the body?"
- Red: "This is in red. Are you stressing …?"
- Highlight: "Yellow here—reminder to fill later, or already decided?"
- Bold: "You bolded '…'. I read that as … — fair?"
- Heading: "'…' looks like heading level N. Its own section?"
- List: "Are these peer points or steps?"

Always offer options + "Other / I'll type it", then stop.

## In-draft command

"I see 'need … below'. Run that search now, or leave TBD?"

## Packaging

"One TOC document, or a folder split by block?"
